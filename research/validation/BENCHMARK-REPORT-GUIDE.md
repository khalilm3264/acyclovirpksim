# Unified benchmark reporting

Run `npm run benchmark:report` (Node >=22, no third-party dependencies).
The command recalculates GMR, geometric mean absolute fold error and inclusive
0.80–1.25/twofold counts from normalized, hashed endpoints. It writes `report.md`,
`report.json` and `summary.csv` to `research/validation/results/benchmark-report/`.
Use `node scripts/benchmark-report.cjs --out /path/to/output` for another directory.
The checked-in [report](BENCHMARK-REPORT.md) is generated by this same command.

## Provenance and scope

The report inputs include the exact source/model commits, engine blobs and SHA-256
hashes of the generating source files. `report-inputs/manifest.json` hashes the
normalized endpoint files. The loader rejects a changed payload or wrong model
revision; it never substitutes the checkout's current engine for the frozen paper.
The snapshot is deliberately usable in a source ZIP or shallow checkout without Git.

- Frozen paper: nine scenarios, 37 endpoints and eight ablations at `8fc1c9d`.
  The pooled paper summary is preserved, with strata and the exclusion of 12
  author-fitted CAPD values shown separately. Parameter bands are not validated
  individual prediction intervals. Both measured and author-fitted references remain labeled.
- Subsequent Turner 2016: all four kidney reconstructions and two variants;
  four Cmax/AUC group-mean endpoints per reconstruction. Clearance is not counted
  again as an independent exposure endpoint.
- Subsequent Manders 2026: all four kidney surrogates and three variants;
  six primary plasma measurements per reconstruction, including one adolescent.
  Case F's potentially contaminated plasma sample, H's missing level, the bounded
  CSF grid and non-reconstructable Sadjadi 2018 observations are excluded from pooled metrics.
- Smith 2016: reported/measured/CG kidney estimates, weight-scaling alternatives
  and infusion-duration assumptions. Dependent descriptors are displayed separately;
  their ratios are not collapsed into a synthetic case-level accuracy score.

As of 13 November 2026, #98 is merged; the Turner source (#96/#97) and Smith source
(#95) are still open PRs. Including their pinned results does not merge or endorse
them. Counts refer to endpoints, not independent subjects. Neither comparison band
is a therapeutic threshold or a clinical pass/fail rule. No cross-study grand total
is generated across the frozen set, repeated sensitivities or later evaluations.

## Independently rerun every pinned source

`npm run benchmark:verify` creates detached temporary worktrees at the exact
source commits, executes the original numerical runners and compares every
normalized result. It checks source-file hashes exactly and numbers with a
cross-platform tolerance of `1e-6 * max(1, abs(a), abs(b))`.
Temporary worktrees are removed after execution. No scripts run in or overwrite
the user's working tree, and no network fetch happens automatically.

A complete Git history is required for this optional verification; if a pinned
commit is missing, the error gives an explicit `git fetch origin COMMIT` command.
Turner and Smith PR objects may need fetching before they are merged.
Refresh inputs only deliberately with `node scripts/benchmark-report.cjs --refresh-inputs`.
This regenerates from the same immutable pins; updating pins is an explicit code
change requiring source review. Regenerate `BENCHMARK-REPORT.md` from the output
when intentionally changing the report presentation.

## Audit user-supplied documents

The standard-library-only Python audit never edits the supplied files:

```sh
python scripts/audit-manuscript.py \
  --manuscript /path/AyFlux_Manuscript_final_clean.docx \
  --si /path/AyFlux_Supporting_Information_companion.odt \
  --archive /path/AyFlux_reproducibility.zip \
  --out /path/audit-output
```

It checks SI S1 numerical inputs, all 37 S2 endpoints and their display rounding,
72 S3 ablation cells, main Tables 3/6, internal links, engine provenance, archive
checksums, figure bytes and document synchronization. It emits machine-readable
JSON plus Markdown. Failures exit nonzero; review-only document issues are labeled
separately. The checker targets the current document structure (including figure
relationship IDs); it fails rather than guessing after a structural redesign.
This is artifact consistency checking, not a fresh literature extraction,
clinical validation, or proof of biological model correctness.
