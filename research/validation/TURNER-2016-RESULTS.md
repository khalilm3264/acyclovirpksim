The model is pinned to `304ce5308ea78907d18b07d8670c164295829eb3`, engine blob `17971df66e0a97b4d382572a582d35c444a3c83f`. The runner verifies both the engine blob and unchanged protocol text. No parameter was selected or tuned from these results.

The source is Turner RB et al., 2016, [DOI 10.1128/AAC.02010-15](https://doi.org/10.1128/AAC.02010-15), Tables 1–2. Published outcomes were read before protocol preparation. These are retrospective group-mean reconstructions of seven obese and seven normal-weight oncology inpatients. Individual covariates and their joint distribution are unavailable.

## Primary reconstruction

The primary kidney inputs are reported indexed eGFR multiplied by mean BSA / 1.73, giving 124.17 and 92.08 mL/min. These are entered as manual CrCl surrogates. Actual PK scaling weights are 120.5 and 61.2 kg. Actual reported mean administered doses are 285 and 303 mg IV over 1 h.

Among the four co-primary Cmax/AUC comparisons, the default gives 1/4 within the prespecified 0.80–1.25 band and 3/4 within twofold. The renal ×0.75 variant gives 2/4 and 4/4, respectively. The narrower band highlights modest multiplicative discrepancies. The twofold band matches the existing manuscript's descriptive comparison. These bands do not establish clinical predictive performance or bioequivalence.

The variant lowers the obese AUC error from −53.5% to −39.2%, and the normal-weight AUC error from −31.3% to −10.9%. Normal-weight peak overprediction increases from +4.3% to +13.5%. Both variants reproduce the direction of lower exposure in the obese group, but exaggerate the obese/normal contrast. The observed AUC ratio is 0.633, compared with 0.429 (default) and 0.432 (variant). Cmax ratios are 0.707 observed, 0.468 default and 0.473 with the variant.

## Numerical verification and reproduction

- Every trajectory was finite and nonnegative, with maximum absolute mass residual 1.94 × 10⁻¹² mg.
- Halving the step from 0.025 to 0.0125 h changes Cmax by at most 1.08 × 10⁻⁶ percent across all prescribed cases.
- The maximum difference between AUC0–120 and dose/clearance AUC0–infinity is 3.32 × 10⁻⁷ percent.
- An independent SciPy matrix-exponential solution of the two-compartment constant-infusion equations matches the four primary RK4 Cmax values within 5.69 × 10⁻⁸ mg/L. This verifies numerical integration of the specified equations.
- A repeat execution generated byte-identical JSON and CSV on the same Node version.

To repeat the independent peak check with NumPy and SciPy available, run this from the repository root after generating the JSON.

```python
import json
import numpy as np
from scipy.linalg import expm

with open('research/validation/results/turner-2016/results.json') as stream:
    report = json.load(stream)
for case in report['results']:
    if case['kidney'] != 'absolute-egfr':
        continue
    run = case['individuals'][0]['coarse']
    p = run['params']
    clearance = p['renal'] + p['other'] + p['form']
    rates = np.array([
        [-(clearance + p['q']) / p['vc'], p['q'] / p['vp']],
        [p['q'] / p['vc'], -p['q'] / p['vp']],
    ])
    # One-hour constant infusion. The input rate equals the one-hour dose.
    amounts = np.linalg.solve(rates, expm(rates) - np.eye(2)) @ np.array([run['config']['dose'], 0])
    assert abs(amounts[0] / p['vc'] - case['prediction']['peak']) < 1e-6
```
