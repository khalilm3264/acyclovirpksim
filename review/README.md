# AyFlux readable source review

This is a **non-deployed review copy** of the existing `public/index.html` from the main branch. The JavaScript has additional line breaks after statement terminators outside recognized strings and comments, making dense statements easier to inspect. It is not a full semantic refactor, and it has not been browser-tested. The live application continues to use `public/index.html` unchanged.

Open `index.readable.html` here for review. Do not deploy it without testing the pharmacokinetic simulation, dosing, and dialysis modes.
