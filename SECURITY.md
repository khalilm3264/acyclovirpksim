# Security policy

AyFlux is a public educational modeling application. Please do not file public issues containing vulnerabilities, private medical data, access tokens, credentials, or personally identifiable information.

Report security problems privately to **contact@ayflux.org**. Include a non-sensitive description, reproduction steps, and affected paths or versions, but do not attach real patient records.

No fixed disclosure or response timelines are guaranteed. Do not use the simulator for patient care.

To report ordinary functional bugs, use the GitHub issue templates with **synthetic** examples.
