# AyFlux

AyFlux is an educational acyclovir and valacyclovir pharmacokinetics simulator with renal function and dialysis scenarios.

## Run

Open `index.html` in a browser, or serve the repository as a static website (for example, through GitHub Pages). The simulator is a browser-based application; some plotting features depend on external JavaScript libraries and connectivity.

## Deployment

For GitHub Pages, configure **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`. The site will publish from `index.html` after GitHub Pages is enabled.
