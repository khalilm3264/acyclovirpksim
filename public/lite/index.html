Model assumptions and sources

Lite reuses the core AyFlux acyclovir/valacyclovir PK implementation and integrates each dosing and treatment boundary. It uses one nominal parameter draw, not a calibrated patient forecast. Default inputs mirror the older Renal PK Lab v2 example: 70 kg, CrCl 5 mL/min, acyclovir 350 mg IV every 24 hours, simulation 96 hours, HD at hour 24 for four hours, repeated every 48 hours; CRRT effluent 25 mL/kg/h. CAPD and APD now use the current AyFlux exploratory dialysate-transfer model, not v2's constant peritoneal clearances.

The CMMG CSF partition is not displayed here. Oral valacyclovir uses an assumed absorption model. PD and CMMG parameters have important uncertainties. For equations, references and evidence limitations, see model methods.
