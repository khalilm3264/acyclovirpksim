Where did the input go?

Widths show mg of acyclovir-equivalent input accounted for by the selected time. Oral input includes only the model-bioavailable acyclovir equivalent; unabsorbed tablet mass is outside this balance. CMMG formation is cumulative acyclovir converted, not current CMMG mass. PD fluid is counted separately from drug discarded at modeled exchange/session boundaries. CSF is excluded because it is not an integrated mass compartment. Intercompartmental recirculation is represented by amounts remaining, avoiding double counting.
